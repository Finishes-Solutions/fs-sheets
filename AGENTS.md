# Product appearance

The user explicitly prefers a monochrome interface. Use white, neutral grays,
and charcoal for application navigation, backgrounds, buttons, cards, planning
screens, and report document styling. Do not introduce green, teal, olive, or
other colored tints to the application chrome without an explicit user request.
Preserve user-selected cell colors, imported workbook formatting, and meaningful
error indicators; do not use a global grayscale filter.
